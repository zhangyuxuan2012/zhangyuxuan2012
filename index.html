网易云歌词转换器

把网易云音乐下载的 .lrc 歌词（JSON 增强格式）转成标准 LRC，点读笔、车载播放器、K 歌软件等设备可直接识别。文件名保持不变，原文件不受影响。

转换结果

关于网易云歌词：从网易云音乐 PC 端 / 移动端下载的 .lrc 歌词，词曲作者信息常以 JSON 片段混入（{"t":0,"c":[{"tx":"作词: ..."}]} 这样的行），普通播放器会把整行当成歌词或直接报错。
本工具会自动解析这类行，把 JSON 里的时间戳（毫秒）与文字展开成 [mm:ss.xx] 标准时间轴；负时间戳、链接字段（li/or）会被安全过滤，[offset:]/[length:] 标签丢弃，全部内容按时间排序，保证在任何标准播放器上都显示正常。
